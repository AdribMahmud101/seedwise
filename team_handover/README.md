# SeedWise — team handover

SeedWise helps smallholder farmers in Rangpur, Bangladesh decide what to plant, when, and how — using NASA Earth data, two fine-tuned AI models and a grounded AI assistant called Planty.

- Live: https://seedwise.onefusionlab.systems
- Code: https://github.com/AdribMahmud101/seedwise (release v1.2.0)

| File | What it covers |
|---|---|

| [02-video-showcase-240s.md](02-video-showcase-240s.md) | The visual "wow" moments ranked for the 4-minute video, with a shot plan |
| [03-nasa-data-and-ai.md](03-nasa-data-and-ai.md) | Which NASA data we use, how, what we combine it with, and how the AI stays grounded |
| [04-model-finetuning-report.md](04-model-finetuning-report.md) | The NASA open model we fine-tuned (Prithvi-EO-2.0) and our forecast model, with results |

Three prepared fields are used throughout: **Mithapukur (01)**, **Pirganj (02)** and **Gangachara (03)**.
