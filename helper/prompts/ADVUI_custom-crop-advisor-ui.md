# ADVUI · Rotation studio: "Plan your own crops" AI decision helper (UI) — URGENT, owner wants it in ~20 min

Owner: crops are fixed today, but a farmer may want hybrid Aman + strawberry, or only mango. Add a custom option; the system generates the best plan for it and is **brutally honest — declines** if not suitable. The backend route `/api/rotation-advisor` is being written by the supervisor in parallel (do NOT edit worker/index.js). Build ONLY the UI in `src/legacy/rotations.js` (+ a new `src/legacy/advisor.js` if cleaner) and `app/rotation-tool.css`. Mobile first. Keep it simple, ship fast, commit early.

CONTRACT — request: `POST /api/rotation-advisor` JSON
`{ lang: 'en'|'bn', mode: 'rotation'|'single'|'mixed'|'orchard', crops: string[] (1–5, each ≤40 chars), notes: string (≤300), context: { fieldId, fieldName, areaHa, irrigation, budget, soil: 'pH 6.1, OM 2.6 %, clay loam', outlook: <outlookSummaryLine>, flood: <floodSummaryLine> } }`
(get context from existing helpers: field(), field profile irrigation/budget, soil data used on the page, `outlookSummaryLine`/`floodSummaryLine` from outlook-flood.js).
Response (success 200): `{ verdict: 'recommended'|'possible_with_conditions'|'not_suitable', title, summary, calendar: [{ month: 1–12, crop: string|null, stage: 'sow'|'grow'|'harvest'|'fallow'|'orchard' }] (12 items), reasons: string[], risks: string[], requirements: string[], alternatives: string[], confidence: 'low'|'medium'|'high', evidence: [{ id, title, url }], source: 'muse-ember-1.0' }`. Errors: `{ error: 'unavailable'|'rate_limited'|'not_configured'|'bad_request' }`.
