# PLANUI · Planting planner: polished interactive UI + Planty chat panel (UI shell only)

Page: #planner (`src/legacy/planner.js`, styles `app/style.css` / `app/studio.css`; 3D lives in `src/legacy/planner3d.js` — ANOTHER CARD (PLAN3D) is rewriting the 3D, so do not edit planner3d.js beyond the public API you call). Mobile is the main screen; laptop equally polished.

1. **Settings panel redesign** (Crop, Usable area %, Row spacing cm, Within-row cm, and any other numeric inputs): every number gets a range slider + compact number box, synced both ways, with sensible min/max/step per crop (use the crop defaults already in the code/data; e.g. rice 15–30 cm, potato rows 50–75 cm / 20–35 cm, mustard 25–40 / 5–15…), unit labels, live value bubble, ≥44 px touch targets, keyboard + aria. Crop chooser as visual cards/chips with a small crop icon (original SVG) instead of a bare select. "Reset to recommended" per crop.
2. **Live results**: Plants to sow / Seed you need, usable area, rows × plants per row, spacing, harvest illustration — update instantly with a smooth number tween (no layout jump). Keep truth labels (Scenario / Measured · by farmer / Estimated) and the source link.
3. **Planty chat panel (UI only, no backend yet)**: a docked panel/drawer: laptop = right-side panel next to settings (collapsible); phone = floating Planty button bottom-right opening a bottom sheet. Planty = ORIGINAL minimal seedling mascot as inline SVG (two leaves, simple face, 2–3 poses via CSS: idle, thinking, happy). Contents: greeting, 3–4 suggestion chips relevant to the current crop/settings ("Is 20×20 cm right for Aman rice?", "How much seed do I need?", "What if I leave 15 % for bunds?"), message list, input + send. Wire to a single function `askPlanty({ question, context })` in a new `src/legacy/planty.js` that currently returns a clear "Planty's AI connection is not set up yet" message (NO fake/canned AI answers). Context object = field id, crop, spacing, usable %, counts — ready for a backend later. Bengali + English.
4. Layout: laptop = 3D preview left (large), settings + results right, Planty panel collapsible; phone = 3D on top, sticky compact results bar, settings below, Planty FAB. No horizontal overflow at 412 px.
Tests: slider/number sync + clamping; recommended defaults per crop; askPlanty returns the not-configured message and receives context.
