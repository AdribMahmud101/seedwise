# PLANTYAI · Planty chat backend on Cloudflare Workers using Meta Muse Ember

Site = Cloudflare Workers static assets (`wrangler.jsonc`: assets dir ./out, custom domain). Front-end chat already exists: `src/legacy/planty.js` → `askPlanty({ question, context })` currently returns a "not set up" message.

1. **Worker**: add `worker/index.js` (ES module) and update `wrangler.jsonc`: `"main": "worker/index.js"`, assets `{ "directory": "./out", "binding": "ASSETS", "not_found_handling": "404-page", "run_worker_first": ["/api/*"] }`. Everything not /api/* is served from ASSETS unchanged (static site must keep working offline/PWA).
2. **POST /api/planty** (JSON in/out, CORS same-origin only): body `{ question: string ≤ 600 chars, lang: "en"|"bn", context: {...} }`. Whitelist context keys (fieldId, fieldName, crop, rowSpacingCm, withinRowCm, usableAreaPct, areaHa, plantCount, seedKg, month, rotation, truth labels) and coerce types; drop anything else. Reject other methods/oversize (413/400). Basic abuse guard: per-IP limit (e.g. 20 req / 10 min) using an in-memory Map (best-effort; comment `shortcut:` noting it resets per isolate) + `cf-connecting-ip`.
3. **Upstream**: `POST https://api.meta.ai/v1/chat/completions` with `Authorization: Bearer ${env.MUSE_API_KEY}`, model `muse-ember-1.0` (also allow env.PLANTY_MODEL override), `max_tokens` ~350, temperature 0.3, 20 s timeout via AbortController. System prompt: Planty = friendly, concise planting companion for smallholder farmers in Rangpur, Bangladesh; answer in the user's language (Bengali if lang=bn), ≤ 120 words, practical; use ONLY the numbers in the provided context for this field and say clearly when something needs a local test/extension officer; never invent measurements, prices or chemical doses; for pesticide/fertiliser doses refer to DAE/BARC guidance; if off-topic, steer back gently. Include the context JSON in a separate system/user message.
4. **Errors**: never leak upstream bodies or the key; return `{ answer, source: "muse-ember-1.0" }` or `{ error: "unavailable" }` (503) / `{ error: "rate_limited" }` (429). If MUSE_API_KEY is missing → 503 `not_configured`.
5. **Front-end**: `askPlanty` calls `/api/planty` (POST, 25 s timeout), shows a typing state (Planty "thinking" pose — `plantyMascot('thinking')`), renders the answer as plain text (escape HTML; keep line breaks), then happy pose. Offline / error → friendly bilingual fallback ("Planty can't reach the internet right now — your planner numbers still work offline."). Small footer: "AI answers can be wrong — check with your local extension officer." Remove the "UI preview · No AI advice yet" note and the "AI connection not set up" pill once a real answer arrives (keep the pill if 503 not_configured).
6. **NEVER** put any API key in the repo, client code, logs, tests or briefs. The owner/supervisor sets it with `wrangler secret put MUSE_API_KEY`. Do not run `wrangler deploy` or `wrangler secret` yourself.
Tests (node --test, mocked fetch): validation (method, size, lang), context whitelisting, rate limit, upstream request shape (URL, model, auth header present but value from env), error mapping, missing key → 503, front-end askPlanty success/offline paths.
Acceptance: eslint no-undef clean on changed src (`npx eslint@8 --no-eslintrc --env browser,es2022 --parser-options=sourceType:module --parser-options=ecmaVersion:latest --rule 'no-undef:error' <files>`; worker file with `--env worker` or globals as needed); `npm test`; `npm run build`; `npx wrangler deploy --dry-run` succeeds. Never touch package-lock.json/node_modules. Commit.
