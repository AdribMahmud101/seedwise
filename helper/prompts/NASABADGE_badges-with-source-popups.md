# NASABADGE · NASA data badges with source popups, app-wide (mentor's top priority)

Goal: every place the app shows a value that genuinely comes from NASA data gets ONE compact NASA badge. Tapping/clicking (or hovering on desktop) the badge opens a small popup with: dataset name, ONE plain-English line saying what it tells the farmer here, resolution · date/period, and a source link (opens in a new tab, rel="noopener"). Concise, uncluttered, high focus.

Existing style to reuse: `.nasa-chip` (NASA blue #0b3d91 pill) and `.has-nasa` in `app/studio.css`; already used in the 3D soil card (Root zone = NASA POWER, `src/legacy/studio3d.js` soilDetailHtml) and the soil panel moisture tile (NASA SMAP, `src/legacy/rotations.js` panelWhatIsUnderMyField). Turn these into the shared component.

1. **One shared helper** e.g. `nasaBadge(key)` in `src/legacy/ui.js` (or a small new module) + a registry `{ key: { label, name, line, res, url } }` with bilingual text (t(en, bn)). Popup: `<button class="nasa-chip" aria-expanded aria-controls>` + a small popover element; tap toggles, Esc / outside tap closes, hover-out closes after ~300 ms unless clicked (pinned). One popup open at a time. Works at 412 px (stays inside viewport) and with keyboard.
2. **URLs and facts must come from the repo's own data files** (`public/data/*.json` `source`/`url`/`retrievedAt` fields, `reports/` or specs) — never invent URLs. If a file has no URL, use the dataset's official NASA landing page you can verify (e.g. power.larc.nasa.gov, smap.jpl.nasa.gov / nsidc.org SMAP L4, gpm.nasa.gov IMERG, lpdaac NASADEM, firms.modaps.eosdis.nasa.gov, landsat.gsfc.nasa.gov). curl -sI each URL; must return 200/301/302.
3. **Find every genuine NASA use**: grep `src/legacy/*.js` and `public/data/*.json` for POWER, SMAP, GPM/IMERG, NASADEM/SRTM, Landsat/HLS, FIRMS/MODIS/VIIRS, GRACE, etc. Badge each place it is displayed (rotation studio layers e.g. Elevation & contours / Water flow use NASADEM; root zone; soil panel moisture; past seasons charts; water & resilience; disaster recovery; my field), one badge per card/section, placed by the title.
4. **Never badge non-NASA sources**: SoilGrids (ISRIC), Sentinel-1/2 (ESA Copernicus), Esri imagery, Fan et al. 2017 water table model, FFWC, BARC/BRRI trials. No badge there.
5. Tests: registry entries have https URL, name, line (en+bn); helper renders aria attributes; no badge rendered for a Sentinel/SoilGrids source. Keep existing 301 tests passing.
Files: `src/legacy/ui.js`, `src/legacy/studio3d.js`, `src/legacy/rotations.js`, other page modules as found, `app/studio.css`/`app/style.css`, tests. Keep diffs focused; don't restyle unrelated UI.
Verify quickly at 1366×768 and 412×915@2.625 on #rotations and one other page: badge visible, popup opens/closes, link correct. Commit as soon as it works — no long screenshot sweeps.
Acceptance: `npx eslint@8 --no-eslintrc --env browser,es2022 --parser-options=sourceType:module --parser-options=ecmaVersion:latest --rule 'no-undef:error'` on every changed src file clean; `npm test`; `npm run build`. Never touch package-lock.json/node_modules. Commit.
