# PLANSFIX · After a plan is Ready, pages stop acting like the journey is running; no empty drafts; crop names

MYPLANS2 is merged (My plans #plans, Exit plan sheet, saved list in journey.js, finish → #plans). Browser test findings:
1. **Ready plan still "running"**: after Finish → #plans, revisiting #planner/#field/#rotations still shows the full journey bar (all ✓, Continue, Exit plan, "Finish my plan") and the coach panel (owner complaint: "why it still shows the plan is already completed"). Fix: when the active plan's status is 'ready' (saved as Ready in My plans), the active journey ENDS — clear/detach the active plan (or mark mode 'viewing') so the journey bar, coach, Finish CTA and in-context hand-offs are not shown on #field/#rotations/#planner. Instead show a slim dismissible strip on those pages: "✓ Your plan is ready — View in My plans · Start a new plan" (bilingual). Opening a Ready plan from My plans shows #plan (read-only view) with "← My plans" and an "Edit this plan" action that explicitly re-enters the journey (status back to draft; bar/coach return).
2. **No empty drafts**: Exit → "Save as draft" on a plan with no confirmed field should not create a card — discard silently with a toast "Nothing to save yet". Draft names: when field/rotation missing use "New plan · <date>", never "My field · Rotation · Field · 0 ha".
3. **Crop names**: season chips/labels on #plans (and #plan) show "Aman rice", "Boro rice", "Potato", "Mustard", "Mungbean", "Fallow" (Bengali from cropBn), never raw keys like "aman".
4. Coach should not appear on #plan when viewing a Ready plan (only during an active journey).
Tests for each rule. Verify in Chrome headless 1366×768 and 412×915@2.625: own journey → finish → revisit #planner (strip, no bar/coach) → My plans → Edit this plan → bar returns; new plan → Exit → Save as draft with nothing → no card. Zero console errors. Commit as soon as it works.
