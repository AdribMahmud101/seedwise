# STUDIO5D · Fetch the data the rotation tool still lacks

Owner rule: if data is missing, bring it — don't label it Unknown. Pilot sites = the 3 fields in the app (Mithapukur, Pirganj, Gangachara; use their polygons/centroids from the existing data files). Write Python under `scripts/` in the style of `fetch-soilgrids.py` / `fetch-low-ground.py`; outputs committed as small static JSON in `public/data/`. Secrets: read from env/`.env` only, never print or commit them.

1. **Sentinel-1 water / ponding** → `scripts/fetch-s1-water.py` → `public/data/s1-water.json`. Sentinel-1 RTC (or GRD) via Microsoft Planetary Computer STAC (no key). For 2024 (pre-monsoon, peak monsoon Jul–Sep, Aman, post-flood) per site: VV/VH backscatter grid (≈20 m, field bbox + 200 m), water mask (VV < −18 dB or Otsu), % of field flooded per date. Schema: `{site: {bbox, cell_m, dates:[{date, vv_db:[[...]], water:[[0/1]], flooded_pct}]}}`. Keep total ≤ 1 MB (gzip like moisture-grid if needed). Truth: REMOTE_OBSERVED, source "Sentinel-1 RTC, ESA/Copernicus via Planetary Computer".
2. **Soil nutrients P, K, Zn, B (+ pH, OM, N, S cross-check)** → `scripts/fetch-soil-nutrients.py` → `public/data/soil-nutrients.json`. Best source first: (a) SRDI *Upazila Nirdeshika* / Land & Soil Resource Utilization Guide for Mithapukur, Pirganj, Gangachara (BARC/SRDI fertility class tables: Very low…Very high per nutrient per land type) — find the published values online, transcribe with citation (page/table); (b) if not obtainable, global gridded maps: soil available P (e.g. He et al. / Batjes WoSIS-based), exchangeable K / CEC (SoilGrids `cec`), Zn & B from published global/South-Asia rasters — sample at each site; (c) BARC Fertilizer Recommendation Guide 2018 class-interpretation thresholds for low/medium/optimum. Schema per site: `{nutrient: {value, unit, class_en, class_bn, source, url, year, scale, truth}}`. Every value cited; truth MODELED or REMOTE_OBSERVED (tables = "Estimated · SRDI upazila survey").
3. Tests: schema + value-range tests in `tests/` for both files. Docs: append rows to `docs/credits.md`.
Acceptance: both scripts run end-to-end; `npm test`; `npm run build`. Never touch package-lock.json/node_modules. Commit.
Out of scope: UI wiring (STUDIO5A/5B consume these files), deploy.
